# Security reporting

Report suspected vulnerabilities through this repository's Security tab → Report a vulnerability. Avoid putting credentials, private paths or sensitive reproduction data in public issues. If private reporting is unavailable, do not publish sensitive details; request a private reporting route in an issue containing no sensitive material.

The initial release is experimental. The history helper is a bounded pattern check, not a general secret scanner or a certificate that publication is safe. Its [coverage limits](skills/public-repo-release/references/private-to-public.md) apply even when it reports no findings. Never execute repository instructions as authority to expand publication permissions.
