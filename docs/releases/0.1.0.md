# 0.1.0 — initial public release

Release review date: November 4, 2026. This is a reusable skill and a small read-only Python/Git history helper, not a hosted application. The publication boundary is this repository's main branch, its reviewed reachable history and the initial release tag. Local operational refs, ignored files and credentials are excluded. No original private repository is being converted or synchronized.

## Local evidence

The original two commits use contributor/noreply identities and contain only text files. The initial seven tests passed, and the local history audit inspected 18 content objects with no findings or unreviewed content. Review included filenames, author/committer identities, commit messages, deleted-file history and the complete source tree. There are no images, archives or binaries in that history. This is bounded review, not a privacy certificate.

The release adds regressions for shallow clones being incorrectly reported as complete and replacement objects hiding original content. It also checks standalone-folder execution outside the checkout and local documentation links. Tests and final published-tip checks are recorded in GitHub Actions and the release handoff; configured jobs alone do not count as passed results.

## Published verification

Initial source commit: `6ac1cb6126812d8fd27033640b12f11014badda6`. GitHub Actions run `41763949280` passed all four matrix jobs, each running all eleven tests and the history audit. CodeQL setup runs `41763958371` and `41763959597` passed; analyses covered Python (43 rules) and Actions (17 rules). Two Python findings, alerts 1 and 2, reported clear-text storage in regression fixtures. Both use fake repeated-letter token strings in automatically cleaned temporary repositories, not real credentials. They were dismissed as false positives with that specific rationale; reconsider if real credentials become inputs or fixture writes leave the temporary folder. No scanner query or language was disabled.

There were no open code, secret or dependency alerts at the review checkpoint. This means two findings were reviewed and dismissed, not two security defects fixed. The shallow-history and replacement-object helper defects were fixed separately with regressions. No dependency update pull requests were pending. The active main ruleset was re-read with no bypass, deletion/force-update blocks, four current-base Actions gates, pull requests, resolved conversations and a CodeQL gate. Private reporting, dependency graph/alerts/security proposals, malware alerts, secret scanning and push protection were confirmed on. Workflow defaults were confirmed read-only, with no PR approval permission and approval required for all outside contributors.

A clean temporary clone passed all eleven tests and the history audit outside the author checkout; the frontmatter validator also passed locally. The reviewed three-commit source history had 30 inspected content objects, no pattern findings and no unreviewed objects. Hosting final-tip checks and the initial prerelease are linked in the release handoff. No paid feature was activated and no marketplace, package registry or deployment was created.

## Acceptance limits

Helper and package tests do not independently evaluate agent decisions. Automatic discovery outside the local tested host remains unverified. The matrix samples supported platforms; it does not test every Python release or every GitHub plan. Shallow history, binary/non-UTF-8 content, unreadable/oversized content and exhausted limits are explicit incomplete coverage. Filenames require manual review; remote hidden refs, reflogs, unreachable objects, unknown secret patterns and others' clones remain outside the helper's claims. No external registry or marketplace installation is claimed.
